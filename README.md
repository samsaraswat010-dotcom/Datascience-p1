# BCSE0593: Data Science and Visualization Lab

## Experiment 01: Exploring Kaggle & GitHub

### Objective
Create accounts, download a dataset from Kaggle, perform preliminary dataset analysis using Python, and upload analysis to a GitHub repository.

### Files Included
- `analysis.ipynb`: Jupyter notebook containing EDA code.
- `analysis.py`: Python script performing basic EDA.
- `archive/Titanic_train.csv`: Training dataset downloaded from Kaggle.
- `archive/Titanic_test.csv`: Testing dataset downloaded from Kaggle.

### Code Output / EDA Steps
1. `df.head()` - View first 5 rows of the dataset.
2. `df.info()` - Inspect column data types and structural information.
3. `df.describe()` - Generate summary statistics for numeric features.
4. `df.isnull().sum()` - Check total missing values for each feature.
